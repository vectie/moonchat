# Synthetic mailbox review

`thread.mbox` contains three invented messages using reserved `.invalid` domains.
Two share a Message-ID; the third omits it. The selection explicitly reviews
message 2 before message 1 and names existing human decision owners. Nothing is
sent, no attachment or HTML is executed, and no quoted approval becomes a receipt.

Follow `docs/REVIEW_MBOX_IMPORT.md` from the repository root. Use the exact source
and selection together; changing whitespace in the mailbox requires a new digest.
The agenda retains one pre-existing proposal. The compiled review has three
entries and four pending decisions, with zero decision receipts.
